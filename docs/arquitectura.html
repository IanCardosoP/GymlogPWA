03

Módulos clave

responsabilidad única · qué exporta · de quién depende

app.js

orquestador · 143 líneas

Store, dispatch, navigateTo e initApp. Registra el SW (salvo en localhost), pide almacenamiento persistente y precalienta las imágenes del catálogo tras abrir el Diario.

  • store: currentTab, activeRoutineId, currentSesionId, prefUnit, acentoKey
  • SET_SESION · SET_RUTINA · SET_EXERCISES · SET_PREF_UNIT · SET_ACENTO

db.js

datos · 667 líneas

Única puerta a PGLite. DDL idempotente (CREATE IF NOT EXISTS + ALTER ADD COLUMN IF NOT EXISTS) para migraciones retrocompatibles en el dispositivo de cada usuario.

  • ejercicios · rutinas · rutina_dias · sesiones · series · conf
  • analítica: estadísticas, volumen, PRs, actividad semanal

catalogo.js

lógica pura · 238 líneas

Carga diferida del catálogo estático. Búsqueda bilingüe (es/en) con tokenización, stemming crudo y sinónimos; ranking por solapamiento proporcional. Deriva rutas de imagen desde fuente_id.

  • buscarEnCatalogo · candidatosMatch · urlsParaWarming

analitico.js

lógica pura · 184 líneas

1RM de Epley (0 si es BW, nunca NaN), barras ASCII de 20 chars, preparación de series por métrica, tendencia y racha.

  • 1RM · peso máx · volumen · METRICAS_REGISTRY

csv.js

lógica pura · 111 líneas

Backup completo en JSON (nombre «csv» legado). Export/import con transacción obligatoria BEGIN/COMMIT/ROLLBACK e inserción en lotes. Acepta backups antiguos.

  • BACKUP_VERSION · exportarBackup · importarBackup

telemetria.js

lógica pura · 29 líneas · externo

Beacon anónimo fire-and-forget vía sendBeacon a un Cloudflare Worker con D1. Solo familia de OS. Nunca en localhost ni offline; text/plain para evitar el preflight CORS.

  • detectOS · registrarUso

05

Service Worker — dos cachés independientes

separar el shell del catálogo evita que la presión de espacio purgue ~9 MB de imágenes

Shell versionado

gymlog-v<version>+<sha>

estrategiacache-first + cache-on-fetch. Navegación falla → fallback al shell (index.html).
ciclo vidaPRECACHE en install; activate borra las gymlog-v* viejas → se invalida en cada deploy.

Catálogo estático

gymlog-catalogo · sin versión

imágenescache-first puro (inmutables por nombre de archivo).
jsonstale-while-revalidate; network-first cuando el llamador pide cache:'reload'.
siembracatalogo/instrucciones.json en el install; sobrevive a los deploys.
06

Build & versionado — sello automático

nunca se escribe un CACHE_NAME a mano · el build falla a propósito si el placeholder no está

Vite build → generateBundle · captura JS/CSS hasheados → closeBundle · reemplaza placeholders en dist/sw.js
__APP_VERSION__ → <package.json version>+<sha corto>  ·  __PRECACHE_MANIFEST__ → array JSON del shell.
Cada push a main cambia el sha → CACHE_NAME nuevo → la caché del shell de los clientes se invalida sola. Excluidos del precache: assets/catalogo/** y sw.js.
07

Invariantes no negociables

reglas que cualquier cambio debe respetar

CATÁLOGO

873 ejercicios como JSON estático en public/assets/. Jamás se insertan en la PGLite del usuario. Único vínculo: catalogo_id (TEXT, sin FK).

A03 · SQLi

Prepared statements siempre ($1, $2…). Prohibida la concatenación de SQL.

A01 · XSS

textContent + createElement. Prohibido innerHTML con datos de usuario y eval().

A08 · Integridad

Importación de backup dentro de BEGIN/COMMIT, con ROLLBACK automático ante cualquier fallo.

TIMEZONE

La fecha la captura JS (toLocaleDateString('en-CA')) antes del INSERT. Nunca CURRENT_DATE de SQL.

BW · PESO 0

peso=0 = peso corporal. Epley retorna 0, nunca NaN. El frontend pinta «BW».

CONF · SINGLETON

Una sola fila (id=1), jamás DELETE. Mutaciones aisladas en db.js.

pnpm

Gestor de paquetes exclusivo. Prohibido npm/yarn. Tests en verde antes de cada DONE.

El Diario muestra la rutina completa. Quedan restos: MAX_ROUTINE_SLOTS (diario.js) ya no lo usa nadie, y rutina_ejercicios.activo_hoy es escritura muerta (reordenarEjercicios aún la escribe).
